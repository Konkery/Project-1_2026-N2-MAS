# Project 1/2026-N2-МАС
Проект посвящен разработке BI инструментов нацеленных для обеспечения поддержки внутренних бизнес процессов компании (группы компаний). В рамках данного проекта в том числе разрабатывается универсальный ETL процессор. Проект зарегистрирован как Заказ №2 в рамках рамочного, внутреннего проекта '1/2026-N0-МАС' в структуре ООО "МАС".
Проект - прямой наследник проекта 'PowerQueryScript' который был принудительно прекращен так как был оформлен не по регламенту.
Все наработки 'PowerQueryScript' - полностью перешли в текущий проект.
