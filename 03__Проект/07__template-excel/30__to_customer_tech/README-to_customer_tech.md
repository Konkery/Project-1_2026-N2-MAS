# ДОКУМЕНТАЦИЯ: ТЕХНИЧЕСКАЯ СПЕЦИФИКАЦИЯ TO_CUSTOMER_TECH (тип 30)

---

## 1. НАЗНАЧЕНИЕ И БИЗНЕС-РОЛЬ

Спецификация типа `to_customer_tech` — **техническое приложение к Договору** с заказчиком ГК «ПЕРЕДОВЫЕ РЕШЕНИЯ». Формируется в MS Excel, после согласования конвертируется в PDF и становится юридически значимой частью контракта.

### 1.1. Главные принципы
1. **Полное отсутствие коммерческой информации:** из датасета исключаются все цены, стоимости, НДС, наценки, скидки, поставщики и артикулы. В документе присутствуют только технические характеристики, количества и сроки.
2. **Полнота технической информации:** в отличие от `to_customer_fin`, спецификация включает детальное описание позиции (`DESCRIPTION PRODUCT`) и итоговое примечание для заказчика (`COMMENT CUSTOMER`).
3. **Единый источник:** генерируется ETL-процессором `ProcessingTable` из консолидированной смарт-таблицы `TabSpecificationWork` (мастер-спецификации `work spec`).

---

## 2. КЛАССИФИКАЦИЯ КОНФИГУРАЦИЙ (JSON DSL)

Налоговый режим (ОСНО/УСН) для технической спецификации **не имеет значения** — коммерческие колонки отсутствуют полностью. В отличие от типа 40 (четыре конфигурации), семейство типа 30 состоит из **двух конфигураций**, различающихся только типом контракта и заголовком колонки срока:

### Тип 1. Поставка + Услуги
Универсальная конфигурация для контрактов с отгрузкой ТМЦ и работами (соответствует типам 1 и 3 спецификации `to_customer_fin`). Колонка срока: **«ДЛИТЕЛЬНОСТЬ ПОСТАВКИ, дней»**.

### Тип 2. Только Услуги
Конфигурация для инжиниринговых и сервисных контрактов без отгрузки материальных ТМЦ (соответствует типам 2 и 4 спецификации `to_customer_fin`). Колонка срока: **«ДЛИТЕЛЬНОСТЬ РЕАЛИЗАЦИИ, дней»**.

## 3. ЭТАЛОННЫЕ СТРУКТУРЫ КОНФИГУРАЦИЙ

### 3.1. Общий конвейер (6 МакроБлоков)

| Блок | Команды | Назначение |
| :--: | :------ | :---------- |
| 1 | `ValidationData` + `StrictBlock` | Пред-валидация мастер-спецификации (41 поле, аналогично типу 40) до любых трансформаций |
| 2 | `ColumnFilterFreeData`, `RemoveRowAll` | Изоляция заказа по `NUM PROJECT`; отсечение неотгруженных позиций (`isSHIPPED = false`) |
| 3 | `FilterSpecMaxVer` | Детерминированный отбор старших версий позиций |
| 4 | `ModifyData` | **Обязательный блок скрытой модификации** (протокол `MODIFY FLAG` / `isPROCESSING`, см. README work spec §8); штатно пуст `[]` |
| 5 | `RemoveXorColumn`, `RenameColumn` | Клиентская сетка из 7 технических полей; локализация заголовков |
| 6 | `ColumnSetType` | Фиксация типов (`text` / `int`) для корректного отображения в Excel |

Примечание: команда `FinancialRound` в типах 30 отсутствует в принципе (нет финансовых полей).

### 3.2. Состав итоговых столбцов (Тип 1, Поставка + Услуги)

| № | Исходный столбец (work_spec) | Целевой столбец (to_customer_tech) | Тип данных | Описание |
| :-: | :--- | :--- | :---: | :--- |
| 1 | `NUM FULL SET` | **№** | `text` | Полный иерархический номер позиции |
| 2 | `NAME PRODUCT` | **НАИМЕНОВАНИЕ** | `text` | Наименование оборудования / услуги |
| 3 | `DESCRIPTION PRODUCT` | **ОПИСАНИЕ И ХАРАКТЕРИСТИКИ** | `text` | Подробное техническое описание (строго после Наименования) |
| 4 | `UNITS` | **ЕД ИЗМ.** | `text` | Единица измерения |
| 5 | `QUANTITY TOTAL` | **КОЛ-ВО** | `int` | Общий объем поставки / выполнения |
| 6 | `DURATION SALE $TOTAL` | **ДЛИТЕЛЬНОСТЬ ПОСТАВКИ, дней** | `int` | Срок поставки |
| 7 | `COMMENT CUSTOMER` | **ПРИМЕЧАНИЕ** | `text` | Примечание для заказчика (строго последняя колонка) |

### 3.3. Состав итоговых столбцов (Тип 2, Только Услуги)

Идентичен Типу 1, исключение — строка 6: **ДЛИТЕЛЬНОСТЬ РЕАЛИЗАЦИИ, дней**.

### 3.4. Тестовые шифры проектов

| Конфигурация | `NUM PROJECT` блока 2 |
| :--- | :--- |
| type1 | `27/2025-N1-МАС` |
| type2 | `8/2026-N1-ГОРИЗОНТ` |

### 3.5. Именная конвенция и `IDconfig`

* Файлы DSL-конфигураций: `ProcessingDSL - to customer tech - type{1,2}.json` в каталоге `03__Проект/05__pq-script/01__general/03__etl-processing/ШАБЛОНЫ-JSON DSL/`.
* `IDconfig` в таблице `TabConfigJSON` книги = базовое имя файла без расширения (например, `ProcessingDSL - to customer tech - type1`).
