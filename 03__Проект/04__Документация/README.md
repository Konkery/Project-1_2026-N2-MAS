## Правила ведения

1. Для каждого нормативного вопроса назначается один источник истины.
2. Навигационные документы содержат ссылки, а не конкурирующие копии норм.
3. Изменения канона сопровождаются датой, записью в проектном журнале и проверкой ссылок.
4. Исторические материалы не используются как новые инструкции без отдельного поручения Хозяина.
5. Системный манифест проекта — только корневой `AGENTS.md`; `GEMINI.md` не создается.
