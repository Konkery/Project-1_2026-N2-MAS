# ДОГОВОРНЫЙ КОНТУР {ОФИЦИАЛЬНЫЙ ШИФР}

## Структура

| Каталог | Назначение |
| :--- | :--- |
| `01__В стадии согласования` | Редакции, которые согласовываются сторонами |
| `02__Согласованный` | Согласованная редакция до подписания |
| `03__Подписанный` | Подписанный юридически значимый экземпляр |

## Реестр

| Дата | Номер / файл | Стороны | Версия | Стадия |
| :--- | :--- | :--- | :--- | :--- |

## Правила

1. Продвижение выполняется по циклу «согласование → согласованный → подписанный».
2. Подписанный экземпляр не заменяется последующей редакцией.
3. Дополнительные соглашения связываются с основным договором.
4. `00__raw` запрещен; черновой контур `00__draft` создается только по решению РП.
