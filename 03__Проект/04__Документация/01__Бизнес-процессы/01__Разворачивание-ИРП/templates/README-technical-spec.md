# СПЕЦИФИКАЦИИ ПРОЕКТА {ОФИЦИАЛЬНЫЙ ШИФР}

## Тип проекта и контур

{РАМКА N0 / ПРИКЛАДНОЙ ЗАКАЗ; ОБОСНОВАНИЕ ПРИМЕНЯЕМЫХ ТИПОВ}

Для рамки `N0` допустимы `01__raw_spec`, `10__csv_spec`, `20__work_spec`. `01__raw_spec` является бизнес-каталогом и не подпадает под запрет `00__raw`.

Для прикладного заказа применяются необходимые типы `30__to_customer_tech` … `90__shipment`.

## Правила

1. Master Data изменяется только в `20__work_spec`; производные документы регенерируются и вручную не правятся.
2. В документы заказчика не переносятся поставщики, закупочные цены, наценки, скидки и `COMMENT WORK`.
3. Позиции старшей версии с `isSHIPPED=false` не включаются в документы заказчика.
4. Для УСН-документов запрещены токены `НДС` и `VAT`.
5. {ДОПОЛНИТЕЛЬНЫЕ ПРОЕКТНЫЕ ПРАВИЛА}
