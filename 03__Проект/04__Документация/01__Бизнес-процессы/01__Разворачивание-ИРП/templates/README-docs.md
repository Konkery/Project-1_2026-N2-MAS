# ДОКУМЕНТАЦИЯ ПРОЕКТА {ОФИЦИАЛЬНЫЙ ШИФР}

## Назначение

Раздел хранит организационные, разрешительные и иные документы проекта, не относящиеся к основному рабочему контуру `03__Проект`.

## Переписка

Единый реестр: [Переписка/README-mail.md](./Переписка/README-mail.md).

Категории:

- `01__Входящие` — полученные от контрагентов;
- `02__Исходящие` — направленные контрагентам;
- `03__Третьи лица` — корреспонденция с участием третьих лиц;
- `04__Не официальная` — рабочая неофициальная переписка.

Одно письмо регистрируется один раз. Черновики создаются в `00__draft` только по решению РП.

## Правила хранения

1. Юридически значимое имя и дата документа указываются по подтвержденному экземпляру.
2. Подписанный документ не заменяется черновиком.
3. Системные файлы ОС не являются проектными документами.
