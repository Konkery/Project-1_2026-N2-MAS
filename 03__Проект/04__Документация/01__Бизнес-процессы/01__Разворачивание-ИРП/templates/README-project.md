# РАБОЧИЙ КОНТУР ПРОЕКТА {ОФИЦИАЛЬНЫЙ ШИФР}

## Структура

| Каталог | Назначение |
| :--- | :--- |
| `01__ИД` | Исходные данные |
| `02__ТЗ` | Текстовые и графические материалы ТЗ, опросные листы |
| `03__План-график` | Календарные и сетевые графики |
| `04__Документация` | Инженерная и проектная документация |
| `77__Контрагенты` | Рабочий обмен с контрагентами |
| `temp` | Вспомогательные материалы AI-агента или оператора |
| `tools` | Вспомогательные утилиты, не являющиеся продуктом проекта |

## Контрагенты

```text
77__Контрагенты\
└─ NN__Наименование-контрагента\
   ├─ 01__Media
   ├─ 02__In
   └─ 03__Out
```

- `01__Media` — технические и медиаматериалы контрагента.
- `02__In` — материалы, **полученные от** контрагента.
- `03__Out` — материалы, **переданные** контрагенту.

Шаблонные контрагенты заменяются фактическими только по решению РП.

## Журнал

Журнал: `ai-{файловый-шифр}.md`.

- ведение append-only;
- тематические промты содержат `_исходные данные:_`, `_задача:_`, `_результат:_`;
- исполнение всех тем регистрируется в едином `## 100. ИСПОЛНЕНИЕ ПРОМТОВ` со сквозной нумерацией `100.x`.

## Ограничения

Продуктовые исходники в `tools` не размещаются. Дополнительные `00__draft` создаются только по решению РП.
