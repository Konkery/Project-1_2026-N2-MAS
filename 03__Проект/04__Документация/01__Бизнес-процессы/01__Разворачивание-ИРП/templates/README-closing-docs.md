# ЗАКРЫВАЮЩИЕ ДОКУМЕНТЫ {ОФИЦИАЛЬНЫЙ ШИФР}

## Назначение

Раздел содержит акты, УПД, накладные и другие юридически значимые документы, подтверждающие исполнение обязательств.

## Реестр

| Дата | Номер / файл | Вид | Контрагент | Сумма | Статус подписания |
| :--- | :--- | :--- | :--- | ---: | :--- |

## Правила

1. Документ связывается с договором, счетом, заказом и отгрузкой при их наличии.
2. Статус подписания отражает фактические подписи сторон.
3. Подписанный файл не заменяется неподписанной редакцией.
4. Суммы и налоговые сведения сверяются с исходным документом.
5. Дополнительные подписанные материалы, не относящиеся к закрытию, размещаются в `09__Подписанные документы`.
