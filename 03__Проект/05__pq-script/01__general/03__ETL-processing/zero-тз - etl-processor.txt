такие операции будут в данном блоке обнаружен, впрочем также как и любые иные кроме работы с типами.

Поясняю правила определения требований в части типов к столбцам выходного датасете. Пользователь опроеделяет ключ 
с именем "ColumnSetType", со значением типа массив, как и всех других блоков конфигуратора JSON.
Элементами массива "ColumnSetType" являются объекты "ключ:значение", где в качестве ключа выступает текствое 
имя столбца которому требуется задать тип. В качестве значения выступает одно из ранее определенных пользователем 
констант типов, вот список который ранее был проработан в рамках работы над процессором:

1. "text"	- тип данных ТЕКСТ, пример - 'Налоговая система - упрощенная';
2. "int"	- тип данных ЦЕЛОЕ ЧИСЛО, пример - '123'
3. "float"	- тип данных ЧИСЛО С ПЛАВАЮЩЕЙ ТОЧКОЙ, пример - '1,45';
4. "bool"	- тип данных BOOL (булевый тип), пример - 'true' или 'false';
